# Code of conduct

testor adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, for its issues, pull requests, discussions and any other space where
the project is represented.

In short: be welcoming and patient, assume good intent, criticize ideas rather than people, and
accept that maintainers may remove contributions or contributors that do not follow it.

## Reporting

Report unacceptable behaviour privately to the maintainer,
[Izac Cavalheiro](https://github.com/izaccavalheiro), through the contact on that GitHub
profile. Reports are handled confidentially, following the Covenant's enforcement guidelines
(correction, warning, temporary ban, permanent ban).
